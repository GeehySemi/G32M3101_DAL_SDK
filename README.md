# G32M3101_DAL_SDK
Official software development kit for Geehy G32M3101 microcontrollers.

## Current version

- SDK version: V1.0.5
- Supported device: G32M3101
- Official package date: October 19th, 2026
- Release notes date: October 30th, 2026
- Official download: [G32M3101_DAL_SDK_V1.0.5.zip](https://www.geehy.com/uploads/tool/G32M3101_DAL_SDK_V1.0.5.zip)

## Supported development environments
The package includes projects and resources for Keil MDK, IAR Embedded Workbench, and Eclipse/GCC, together with CMSIS, peripheral libraries, middleware, board support, and examples.
